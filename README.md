# Perro

Programación II - Unidad 1 - Ejercicio 4

## Consigna
Registrar mascotas de una clínica veterinaria y determinar si
requieren revisión anual según su edad.

## Lógica
La clase encapsula `nombre`, `raza`, `edadAnios` y `pesoKg`.
`requiereRevisionAnual()` evalúa si `edadAnios > 7` y retorna un
mensaje personalizado con el nombre del perro según corresponda. En
el `main` se instancian dos objetos distintos para probar ambas ramas
de la condición.
